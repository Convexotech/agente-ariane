        https://openrouter.ai/


Na tela de configuração do deploy do Netlify, procure pela seção Build settings and environment variables.

Clique no botão Add environment variables.

Preencha com os dados da sua chave do OpenRouter:

Key (Chave): API_KEY

Value (Valor): cole_sua_chave_do_openrouter_aqui

Clique em Deploy site.
